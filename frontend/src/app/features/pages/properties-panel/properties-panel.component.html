Build tips

  • Use User Input for every form field (dropdown, date, number, file, radio…).
  • Set any Database key you want — no fixed list. Use From label to auto-name it.
  • Mark Required / Unique as needed.
  • Save Layout creates/updates the page’s Mongo collection automatically.
  • Button Actions → Submit this form saves rows; Navigate for Cancel.
